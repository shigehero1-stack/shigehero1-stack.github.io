stock-yt uploader

stock-yt uploader は、YouTube チャンネル「stock-yt」の運営者本人が、自分で作成した株式市場の解説動画を自分のチャンネルへアップロードするために使う個人用ツールです。

機能

  • 運営者のパソコン上で生成した動画ファイルを、YouTube Data API を通じて運営者自身の YouTube チャンネルに非公開でアップロードします。
  • 接続先チャンネルの名前を表示して、正しいチャンネルに接続されていることを確認します。

利用者

このツールはチャンネル運営者本人のみが使用します。第三者に提供したり、他の利用者のアカウントに接続したりすることはありません。
