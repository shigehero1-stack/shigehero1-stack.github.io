プライバシーポリシー

本ポリシーは、stock-yt uploader（以下「本ツール」）が Google ユーザーデータをどのように取り扱うかを定めるものです。

1. 本ツールの性質

本ツールは、YouTube チャンネル「stock-yt」の運営者本人が、自身のチャンネルへ動画をアップロードするために使用する個人用のソフトウェアです。運営者以外の利用者はいません。

2. 取得する情報と権限

本ツールは Google の OAuth 2.0 を通じて、次の権限の許可を求めます。

  • youtube.upload：運営者自身のチャンネルへ動画をアップロードするため
  • youtube.readonly：接続先チャンネルの名前を確認するため

本ツールが取得するのは、接続先チャンネルの名前と ID、およびアップロードした動画の ID のみです。

3. 情報の保存と利用

認証情報（リフレッシュトークン）およびアップロード記録は、運営者のパソコン内にのみ保存されます。外部のサーバーへ送信・保存することはなく、第三者に提供・販売することもありません。取得した情報は、上記の目的以外には利用しません。

4. 情報の削除

運営者は、パソコン内の認証情報ファイルを削除するか、Google アカウントのアクセス許可ページから本ツールのアクセスを取り消すことで、いつでも本ツールによるアクセスを停止できます。

5. Google API サービス ユーザーデータ ポリシーの遵守

本ツールによる Google API から取得した情報の利用は、Google API サービス ユーザーデータ ポリシー（限定使用の要件を含む）に従います。

6. お問い合わせ

本ポリシーに関するお問い合わせは、Google Cloud の OAuth 同意画面に登録したサポートメールアドレスまでご連絡ください。
